¿Qué es el Carry Trade de Bonos?

Esta estrategia consiste en vender USD al tipo de cambio MEP actual de $--, comprar bonos en pesos, mantenerlos hasta el vencimiento y recomprar los dólares. El porcentaje que se presenta en la tabla es el rendimiento directo de esta estrategia completa medido en dólares.

🎯 Concepto del Carry Trade

Consiste en capturar el diferencial entre las altas tasas en pesos argentinos y las bajas tasas en dólares, esperando que la devaluación del peso sea menor al diferencial de tasas durante el período de inversión.

📊 Banda Cambiaria

El análisis considera la banda cambiaria del BCRA que inició el 14/04/2025 con un crawling peg del 1% mensual. A partir del 01/01/2026, las bandas evolucionan según la inflación T-2 proyectada por el Relevamiento de Expectativas de Mercado (REM) del BCRA. El "techo de la banda" representa el escenario más conservador de devaluación.

⚠️ Factores de Riesgo

Los principales riesgos incluyen: devaluación acelerada del peso, cambios en la política monetaria, riesgo de crédito soberano, y volatilidad de los mercados financieros locales.

Metodología: Estimación de Bandas Cambiarias

¿Cómo se estiman las bandas?

Las bandas cambiarias evolucionan diariamente según la inflación T-2 (dos meses atrás), utilizando datos reales del INDEC cuando están disponibles y proyecciones del REM para meses futuros.

Fórmula de evolución diaria

Bandadía = Bandadía-1 × (1 + tasa_diaria)

Donde: tasa_diaria = (1 + inflación_mensual_T-2)1/días_del_mes - 1

La inflación T-2 corresponde a la inflación de dos meses atrás. Por ejemplo, la banda de marzo 2026 evoluciona según la inflación de enero 2026.

Prioridad de datos para la banda

  1. Datos reales INDEC — Se priorizan siempre sobre cualquier proyección
  2. Proyecciones mensuales REM — Mediana de ~45 economistas profesionales
  3. Calibración con proyección anual REM — Para meses sin dato mensual específico
  4. Fallback conservador (2,0%) — Solo si no hay ningún dato disponible

API REM - BCRA (Datos Abiertos)

Los datos de inflación proyectada provienen de la API REM - BCRA, un proyecto open-source que automatiza la lectura, normalización y distribución del Relevamiento de Expectativas de Mercado del Banco Central.

Pipeline de datos

1
Descarga automática

GitHub Actions descarga el archivo Excel del REM desde bcra.gob.ar (días 1-15 de cada mes)

2
Procesamiento

Python + Pandas parsea, normaliza y estructura 19 tablas JSON con medianas, percentiles y proyecciones de ~45 economistas

3
Distribución

Los datos se almacenan en Cloudflare R2 y se sirven globalmente via Cloudflare Workers con cache de 1 hora
